How FigureNG works

The principles behind the tools.

01

Built for Nigeria

Calculations use Nigerian currency, rules and local context where applicable.

02

Show the workings

Important calculations should explain how the final number was reached.

03

No unnecessary sign-up

Tools should be usable without creating an account for basic calculations.

04

Designed for phones

Every tool is built to remain usable on smaller screens.

Why FigureNG?

Many financial questions are easier to answer when the numbers are presented clearly.

FigureNG is being built as a practical collection of calculators for Nigerians, starting with salary and borrowing tools and expanding gradually.

Clear results The important number is easy to find without hiding the details.
Transparent calculations Where methodology matters, the calculation and assumptions are explained.
Practical tools Each calculator is designed around a real-world question.
